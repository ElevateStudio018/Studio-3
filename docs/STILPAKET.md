# 20 stilpaket för STUDIO 3

Varje stilpaket är ett komplett utseende för hela sajten: färger, typsnitt, former och effekter. Alla paket ligger i [`public/assets/js/themes.js`](../public/assets/js/themes.js) och kan:

- **förhandsgranskas** live på `/?stil=<id>` (t.ex. `/?stil=riksdag`) – en flytande bar låter dig bläddra mellan alla 20,
- **jämföras** sida vid sida på `/stilpaket`,
- **aktiveras** för hela sajten i admin under *Innehåll & stil* (eller direkt på `/stilpaket` när du är inloggad).

## Effekter

| Effekt | Vad den gör |
|---|---|
| grain | Svagt filmkorn över hela sidan (studiokänsla) |
| ticker | Nyhetsrad i accentfärg längst ned i heron |
| glow | Neonglöd på rubriker och siffror |
| stripes | Diagonala sportränder i sektionsbakgrunder |
| thick | Tjocka ramar och hårda skuggor |
| split | Hero tonad i två färger (vänster/höger) |
| sunset | Solnedgångsgradient i bakgrund och hero |
| glass | Frostat glas på kort och fält |
| scanlines | Tv-linjer som på en gammal CRT |
| bigfocus | Större text och extra tydliga fokusramar (tillgänglighet) |
| sticker | Lätt roterade etiketter och knappar |

## Lägga till ett eget paket

Kopiera ett objekt i `THEMES`, ge det ett nytt `id` och ändra `vars`, `display`, `body` och `fonts` (Google Fonts-parametrar). Inget annat behöver ändras – sajten, stilpaket-sidan och admin plockar upp det automatiskt.
